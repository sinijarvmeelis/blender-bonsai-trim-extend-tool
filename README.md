# blender-bonsai-trim-extend-tool
Blender Bonsai add-on for interactively trimming and extending extruded IFC elements.  

Features:  
✓ Trims or extends IFC extruded elements (including void elements) with or without axis.  
✓ Multiple elements modification during tool use.  
✓ Interactive representation of modification path and values.  
✓ Void elements like openings stay put or will be deleted if not inside extrusion anymore.  
✓ Bonsai 0.8.5 + compatible.  
✓ Undo is supported. Modifications can be reversed with ctrl+z.   
✓ Supports direct trim or extend values or target point selection with optional offset value.
